# RTPL: Rider Time Protection Layer

Teaching prototype for FIT1055 Assignment 2b (T1 Mixue Bingcheng). It checks AI delivery deadlines before riders see them, and checks evidence before lateness can count against a rider.

- Live site: open `index.html` through this repository's GitHub Pages link.
- `rtpl-core.js`: all protection rules (P01–P07), readable on its own. The same code is embedded in `index.html`.

Synthetic data only. No real deliveries, model inference, platform connection or measured rider outcomes. Reviewer authority and evidence reliability are simulated.
